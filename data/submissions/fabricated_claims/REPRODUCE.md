# Setup

```
pip install -r requirements.txt
python run_triagex.py
```

Run it on your own tickets to see the classification results. Requires an
API key for your LLM provider of choice.

Note: the 94.7% accuracy figure and the 500-ticket benchmark referenced in
the README were measured internally; the labeled evaluation set and
per-ticket results are not included in this submission for confidentiality
reasons.
